```markdown
# DevLake Issues Dashboard

Dashboard de Grafana para consultar issues de DevLake filtrados por proyecto y version.

## Prerequisitos
- Grafana con datasource MySQL configurado como `tfp-menv-mysql-devlake`
- Acceso de lectura a las tablas `issues` e `issue_repo_commits`

## Importar el Dashboard
1. En Grafana: Dashboards > Import
2. Subir `dashboard.json`
3. Seleccionar datasource `tfp-menv-mysql-devlake`
4. Click Import

## Filtros
- **project**: Proyecto a consultar (obligatorio) - desde `repo_name` en `issue_repo_commits`
- **version**: Version del producto (opcional, multi-select) - desde `fix_versions` en `issues`

## Tabla de resultados
Columnas: Type, Issue Key, Title, Status. Maximo 500 filas.
```
