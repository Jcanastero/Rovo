# Task: Table Panel

## Description
Crear el panel de tabla principal del dashboard. La tabla muestra los issues del proyecto y version seleccionados, con las columnas: Type, Issue Key, Title, Status. Requiere un JOIN entre `issues` e `issue_repo_commits` para filtrar por proyecto.

## Technical Details

**Query base:**
```sql
SELECT
  b.name          AS "Project",
  i.original_type AS "Type",
  i.issue_key     AS "Issue Key",
  i.title         AS "Title",
  i.status        AS "Status",
  i.fix_versions  AS "Fix Version"
FROM issues i
INNER JOIN board_issues bi ON i.id = bi.issue_id
INNER JOIN boards b ON bi.board_id = b.id
WHERE bi.board_id IN (${project})
  AND $__timeFilter(i.created_date)
  AND i.original_type IN ('Request Support', 'Bug Support IT')
  AND (
    '${version}' = '%'
    OR ('${version}' = '(Sin versión)' AND (i.fix_versions IS NULL OR i.fix_versions = ''))
    OR ('${version}' != '(Sin versión)' AND i.fix_versions LIKE '${version}')
  )
ORDER BY i.created_date DESC
LIMIT 500
```

Confirmado en Task 001:
- Campo Issue_key: `issue_key` (varchar 255)
- board_issues: columnas `board_id` e `issue_id` confirmadas
- fix_versions: tipo TEXT, puede contener valores compuestos (comma-separated); LIKE con All value `%` cubre ambos casos
- Valores de `type` confirmados: `'REQUEST SUPPORT'`, `'BUG SUPPORT IT'` (todo mayúsculas)

**Configuracion del panel:**
- Type: Table
- Width: 24 (full width en grid Grafana)
- Pagination: habilitada, page size 25
- Footer: mostrar conteo de filas
- Column widths: Type (auto), Issue Key (auto), Title (expand), Status (auto)
