## Technical Details
Queries de inspeccion a ejecutar en Grafana Explore o conexion MySQL directa:

```sql
-- 1. Confirmar columnas de tabla boards (buscar: id, name)
SHOW COLUMNS FROM boards;

-- 2. Confirmar que los 9 board IDs existen en la tabla boards
SELECT id, name FROM boards
WHERE id IN (
  'jira:JiraBoard:1:333',
  'jira:JiraBoard:1:99',
  'jira:JiraBoard:1:450',
  'jira:JiraBoard:1:431',
  'jira:JiraBoard:1:361',
  'jira:JiraBoard:1:356',
  'jira:JiraBoard:1:335',
  'jira:JiraBoard:1:1618',
  'jira:JiraBoard:1:87'
)
ORDER BY name;

-- 3. Confirmar tabla board_issues y su estructura (board_id, issue_id)
SHOW COLUMNS FROM board_issues;

-- 4. Verificar JOIN boards -> board_issues -> issues
SELECT b.name, bi.board_id, bi.issue_id, i.title
FROM boards b
INNER JOIN board_issues bi ON b.id = bi.board_id
INNER JOIN issues i ON bi.issue_id = i.id
WHERE b.id = 'jira:JiraBoard:1:87'
LIMIT 10;

-- 5. Confirmar columnas de issues (buscar campo Issue_key: number, key, original_key, etc.)
SHOW COLUMNS FROM issues;

-- 6. Valores distintos de status
SELECT DISTINCT status FROM issues LIMIT 50;

-- 7. Confirmar valores exactos de type (esperados: 'Request Support', 'Bug Support IT')
SELECT DISTINCT type FROM issues LIMIT 50;

-- 8. Verificar que los tipos requeridos existen y tienen datos
SELECT type, COUNT(*) as total
FROM issues i
INNER JOIN board_issues bi ON i.id = bi.issue_id
WHERE bi.board_id = 'jira:JiraBoard:1:356'
  AND type IN ('BUG SUPPORT IT', 'REQUEST SUPPORT')
GROUP BY type;

-- 9. Formato de fix_versions (string, comma-separated, JSON?)
SELECT fix_versions FROM issues
WHERE fix_versions IS NOT NULL AND fix_versions != ''
LIMIT 20;
```
