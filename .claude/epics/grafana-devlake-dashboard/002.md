# Task: Dashboard Setup and Template Variables

## Description
Crear el dashboard base en Grafana con titulo, datasource por defecto y las dos template variables: `project` (desde `repo_name` en `issue_repo_commits`) y `version` (desde `fix_versions` en `issues`, dependiente del proyecto seleccionado).

- [ ] Datasource por defecto: `tfp-menv-mysql-devlake`
- [ ] Variable `project` creada y mostrando los proyectos disponibles

- [ ] Dashboard guardado en Grafana

## Technical Details

**Variable `project`:**
- Name: `project`
- Type: **Query**
- Data source: `tfp-menv-mysql-devlake`
- Query:
  ```sql
  SELECT name AS __text, id AS __value
  FROM boards
  WHERE id IN (
    'jira:JiraBoard:1:333',
    'jira:JiraBoard:1:99',
    'jira:JiraBoard:1:450',
    'jira:JiraBoard:1:431',
    'jira:JiraBoard:1:361',
    'jira:JiraBoard:1:356',
    'jira:JiraBoard:1:335',
    'jira:JiraBoard:1:87',
    'jira:JiraBoard:1:1618'
  )
  ORDER BY name
  ```
- Multi-value: Yes
- Include All: Yes
- Refresh: On Dashboard Load
- Nota: El dropdown muestra el `name` del board; el valor que se pasa a las queries es el `id`. Las queries usan `IN (${project})` para soportar selección múltiple y All.

**Variable `version`:**
- Name: `version`
- Type: Query
- Data source: `tfp-menv-mysql-devlake`
- Query:
  ```sql
  SELECT fix_versions FROM (
    SELECT DISTINCT fix_versions
    FROM issues i
    INNER JOIN board_issues bi ON i.id = bi.issue_id
    WHERE bi.board_id IN (${project})
      AND i.original_type IN ('Request Support', 'Bug Support IT')
      AND fix_versions IS NOT NULL AND fix_versions != ''
    UNION ALL
    SELECT '(Sin versión)' AS fix_versions
  ) t
  ORDER BY fix_versions
  ```
- Multi-value: Yes
- Include All: Yes
- All Value: `%`
- Refresh: On Time Range Change
