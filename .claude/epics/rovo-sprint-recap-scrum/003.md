# Task: Fix burndown URL - Resolucion de boardId y sprintId

## Description

Modificar el prompt del agente ROVO para agregar instrucciones claras sobre como resolver `boardId` y `sprintId` a partir del `projectKey` y `sprintName`, y definir el comportamiento cuando los IDs no pueden obtenerse. Esto corrige el Defecto 2: URL del burndown con placeholders literales o IDs incorrectos.

El archivo a modificar es: `ROVO/RovoSprintReportScrum.txt`

## Acceptance Criteria

- [ ] El prompt incluye un proceso paso a paso para resolver `boardId` usando las herramientas disponibles del agente (buscar board por projectKey)
- [ ] El prompt incluye instrucciones para resolver `sprintId` buscando el sprint por nombre dentro del board encontrado
- [ ] El prompt prohibe explicitamente escribir `{{boardId}}` o `{{sprintId}}` como texto literal en la URL final del reporte
- [ ] El prompt prohibe usar IDs de un proyecto distinto al `projectKey` solicitado
- [ ] El prompt define el comportamiento de error cuando los IDs no pueden resolverse: incluir nota accionable en el reporte (no generar URL rota)
- [ ] El archivo `RovoSprintReportScrum.txt` esta actualizado con los cambios

## Technical Details

**Proceso de resolucion de IDs a agregar al prompt:**

```
## BURNDOWN URL RESOLUTION PROCESS

Step 1 - Find Board ID:
  Use your Jira tools to search for boards associated with project {{projectKey}}.
  Select the board whose project key exactly matches {{projectKey}}.
  Extract the numeric board ID. This is your REAL_BOARD_ID.

Step 2 - Find Sprint ID:
  Using REAL_BOARD_ID, search for sprints in that board.
  Find the sprint whose name exactly matches {{sprintName}}.
  Extract the numeric sprint ID. This is your REAL_SPRINT_ID.

Step 3 - Build URL:
  If REAL_BOARD_ID and REAL_SPRINT_ID were found:
    URL = https://appgateinc.atlassian.net/jira/software/c/projects/{{projectKey}}/boards/REAL_BOARD_ID/reports/burndown-chart?sprint=REAL_SPRINT_ID
    Replace {{projectKey}} with the actual project key value.
    Replace REAL_BOARD_ID and REAL_SPRINT_ID with the numeric values found.

  If IDs could NOT be resolved:
    Do NOT write a URL with placeholders or guessed IDs.
    Instead, include this note:
    "Burndown Chart: Could not automatically resolve Board ID or Sprint ID for this project.
     To view the burndown chart manually: In Jira, navigate to your project > Board > Reports > Burndown Chart,
     then select sprint '{{sprintName}}'."

STRICT PROHIBITION:
- NEVER write {{boardId}} or {{sprintId}} as literal text in the final report URL.
- NEVER use board IDs or sprint IDs found for a different project than {{projectKey}}.
- NEVER guess or invent numeric IDs.
```
