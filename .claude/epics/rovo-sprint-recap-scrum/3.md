# Task: Fix JQL - Eliminar openSprints() del flujo de fallback

## Description

Modificar el prompt del agente ROVO para que cuando el usuario provee un `sprintName` explicito, el flujo de queries nunca use `sprint in openSprints()` como fallback. Este filtro excluye silenciosamente los sprints cerrados y es la causa del Defecto 1 (si se confirma en Task #2 como Hipotesis B).

El archivo a modificar es: `ROVO/RovoSprintReportScrum.txt`

## Acceptance Criteria

- [ ] La seccion `## JQL QUERY OPTIONS` del prompt no contiene `openSprints()` en el flujo de fallback cuando `sprintName` es provisto
- [ ] Se agrega una instruccion explicita: cuando `sprintName` es provisto, las queries usan `sprint = '{{sprintName}}'` que devuelve el sprint en cualquier estado (abierto, cerrado, futuro)
- [ ] Alternative Query 2 se reemplaza por una query que funcione para sprints en cualquier estado, por ejemplo: `project = "{{projectKey}}" AND sprint = "{{sprintName}}" ORDER BY status DESC`
- [ ] Si se desea mantener un fallback para "sprint activo cuando no se provee sprintName", se mueve a una seccion separada claramente diferenciada
- [ ] El archivo `RovoSprintReportScrum.txt` esta actualizado con los cambios

## Technical Details

**Seccion a modificar en el prompt:**

```
## JQL QUERY OPTIONS (Try in this order SINGLE LINE - NO BREAKS):
Primary Query: project = '{{projectKey}}' AND sprint = '{{sprintName}}' ORDER BY status DESC, resolved DESC
Alternative Query 1: project = "{{projectKey}}" AND "Sprint" = "{{sprintName}}" ORDER BY statusCategory, resolved DESC
Alternative Query 2 (PROBLEMA): project = "{{projectKey}}" AND sprint in openSprints() ORDER BY statusCategory, resolved DESC  <-- ELIMINAR o condicionar
```

**Reemplazo propuesto para Alternative Query 2:**
```
Alternative Query 2 (Si sprintName es provisto y las anteriores fallan):
project = "{{projectKey}}" AND sprint = "{{sprintName}}" AND sprint not in futureSprints() ORDER BY status DESC
```

**Instruccion a agregar:**
```
IMPORTANT: When {{sprintName}} is provided and non-empty, NEVER use openSprints() or closedSprints() filters.
Always search for the sprint by name regardless of its status (active, closed, or future).
Only use openSprints() if {{sprintName}} is empty or missing.
```

- **Seccion**: `## JQL QUERY OPTIONS`
