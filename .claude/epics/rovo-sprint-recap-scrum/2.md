# Task: Diagnostico - Causa raiz de acceso a sprints cerrados

## Description

Antes de modificar el prompt, confirmar la causa raiz del problema de acceso de otros owners a sprints cerrados. Hay dos hipotesis que deben verificarse en orden:

- **Hipotesis A**: El agente ROVO esta configurado con "Run As Creator" (ejecuta con las credenciales de Jenny en lugar de las del caller), lo que explica por que otros owners no obtienen datos de sprints cerrados.
- **Hipotesis B**: El flujo de fallback del JQL cae en `Alternative Query 2` (`sprint in openSprints()`) cuando la query principal falla para ciertos usuarios, filtrando silenciosamente los sprints cerrados.

## Acceptance Criteria

- [ ] Se ha revisado la configuracion del agente ROVO en el panel de Atlassian Intelligence y se documenta si existe opcion "Run As" y con que valor esta configurada
- [ ] Un owner distinto a Jenny ha ejecutado el agente sobre el sprint cerrado `2026 - 11.0.0 - Sprint 13` (proyecto DID) y se ha capturado el mensaje de respuesta exacto (vacio, error, "no issues found", etc.)
- [ ] Se ha determinado si el problema es Hipotesis A, Hipotesis B, o ambas
- [ ] La causa raiz confirmada esta documentada en un comentario o nota para guiar las tasks #3, #4 y #5

## Technical Details

- **Panel ROVO**: Acceder a Atlassian Intelligence / ROVO Agent Administration > seleccionar el agente "Sprint Recap" > revisar configuracion de ejecucion
- **Proyecto de prueba**: `360 Adaptive Authentication` (key: DID), Sprint: `2026 - 11.0.0 - Sprint 13`
- **Actor para prueba**: Otro owner de DID que no sea Jenny
